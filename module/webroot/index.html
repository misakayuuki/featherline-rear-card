还没有看到用药数据？

卡片需要 Featherline 背屏适配版 提供数据，官方原版暂不提供这个接口。此页面无法检查手机是否已安装 App。

  1. 尚未安装时，从 GitHub 发布页下载安装包。
  2. 打开适配版，进入设置 → 外观 → Featherline 背屏，开启同步并绑定。
  3. 已有数据但未更新时，在 App 的同一页面点击立即同步。

适配版与官方版的数据独立。可通过加密备份恢复，之后需在适配版里继续记录。
